IoU

Intersection / union
—|A ∩ B| / |A ∪ B|

How closely do the regions overlap? Ranges from 0 to 1; higher is better.

Dice

Region similarity
—2|A ∩ B| / (|A| + |B|)

Equals pixel-level F1 for the same binary sets. Its value is not directly comparable to IoU.

GIoU

Enclosure penalty
—IoU − |C ∖ (A ∪ B)| / |C|

Can distinguish some non-overlapping configurations. Negative values are valid.

Training loss

Lower is better
1 − IoU —1 − GIoU —

Training minimizes loss. A higher overlap score corresponds to a lower loss.

OBSERVATION

Why can IoU loss provide no direction?

When separated boxes remain non-overlapping after a small movement, IoU stays at 0 and IoU loss stays at 1. Its positional gradient is zero in that region. GIoU penalizes the uncovered fraction of the enclosing box, providing additional gradients in many non-overlapping configurations.

GIoU is not simply center distance and does not guarantee a unique, optimal direction for every movement. If one box contains the other, or aligned overlapping boxes fill C completely, the penalty is zero and GIoU equals IoU.

Class-aware NMS

Compare boxes only within the same predicted class. Overlapping objects from different classes can survive.

Compare all boxes together, regardless of the predicted class.

Useful when cross-class duplicates should compete. It can suppress real overlapping objects from different classes. Validate the policy on your data.

Metric reference

Different metrics are not directly comparable.
MetricWhat it measuresWhere to use itWhat to watch for
AccuracyOverall fraction correctClassification; pixel accuracy for segmentationImbalance can hide missed targets. With 99% background, predicting background everywhere yields 99% pixel accuracy.
Precision / Recall / F1False positives and missed positivesClassification, detection, or pixelsSpecify thresholds and counting units. F1 is not AP.
IoU / GIoULocalization and regional overlapBox regression and region comparisonGIoU may be negative. One box’s IoU does not describe the entire detector.
DiceSimilarity of binary regionsSegmentation, often biomedical imagesEquals pixel F1 for the same binary sets. Mean Dice cannot be directly converted into mean IoU.
mIoUMean pixel-region overlap across classesSemantic segmentationDefine background inclusion, absent classes, ignored labels, and averaging.
AP / mAPPrecision and recall across a rankingObject detectionmAP averages class APs. Specify IoU settings, interpolation, dataset, and evaluation protocol.
Mask APInstance detection and mask qualityInstance segmentationUses mask IoU for matching. Box AP is not a substitute.
Latency / FPSInference speedDeployment of any vision modelSpecify hardware, resolution, batch size, and pre/post-processing. Throughput is not single-image latency.
